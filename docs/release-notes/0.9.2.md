# System-Ping 0.9.2

## Was 0.9.2 bringt

- **Das Diagramm kann jetzt Punkte.** Rechts in der Kopfzeile des Diagramms: **„Linien“** (wie bisher, eine Kurve pro Ziel) oder **„Punkte“** — jeder Messwert als eigener Punkt. Die Größe des Punkts sagt, wie weit der Wert vom Durchschnitt *seines* Ziels entfernt liegt, gemessen an der Streuung des Ziels: Werte dicht am Durchschnitt bleiben Pünktchen, Ausreißer nach oben wie nach unten werden größer und in der Ausreißer-Farbe gemalt. Der Grund: Das Problem an einer Verbindung sind ihre Ausreißer, und die sind selten — in einer Kurve aus den langweiligen Werten dazwischen sieht man sie kaum. Der Modus wird gespeichert.
- **Der Build sagt, welcher Commit er ist.** In den Einstellungen steht unter „Info“ jetzt `0.9.2 (a102d0a)` — Versionsnummer und der Git-Commit, aus dem das Programm gebaut wurde. Bei einem Fehlerbericht ist das die erste Frage, und das Programm kann sie jetzt selbst beantworten. Bei Builds ohne Git (Quelltext-Tarball) entfällt der Klammerzusatz.
- **Die Einstellungen sind wieder nur Einstellungen.** Die Gruppe „Ziele“ mit zwei Eingabefeldern, „Hinzufügen“-Knopf und drei Vorschlags-Knöpfen ist weg. Ziele legt man oben in der Leiste an — dort, wo Enter ohnehin schon als Bestätigung dient und das neue Ziel sofort gemessen wird.

**macOS** ist ad-hoc signiert, nicht von Apple notarisiert. Nach dem Entpacken einmal ins Programmverzeichnis bewegen und von dort starten; bei Bedarf die Quarantäne mit `xattr -d com.apple.quarantine` entfernen.

**Linux** braucht die Runtime-Bibliotheken, die auch im README stehen (`libegl1`, `libxkbcommon-x11-0` und die X11-Bibliotheken).

Alle drei Dateien sind von GitHub Actions gebaut: jeder Build besteht Clippy, 124 Tests und einen Smoke-Test, der auf macOS und Linux tatsächlich ein Bild malt.
